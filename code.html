~/proyectos/dtmf-audio-decoder

DTMF Audio Decoder

Herramienta en Python para decodificar tonos DTMF (Dual-Tone Multi-Frequency) de grabaciones telefónicas de encuestas. Permite extraer respuestas numéricas de datos de audio, apoyando la recolección de datos que preserva la privacidad en contextos sensibles como estudios de género o salud, con integración directa a plataformas como SurveyCTO.

~/proyectos/parsing-invoices-cl-pe

Análisis de Facturas (Chile y Perú)

Código en Python para extraer datos estructurados de archivos PDF - incluyendo encriptados, sin necesitar una clave de desencriptación. Ideal para procesar facturas electrónicas de Perú y Chile, convirtiéndolas en archivos Excel limpios y analizables.

~/proyectos/random-forest-ira

Detección temprana de enfermedades respiratorias con Random Forest

Este proyecto implementa un Random Forest Regressor para la detección temprana de infecciones respiratorias agudas (IRA) en Perú. El modelo predice la tasa de incidencia semanal por región usando datos climáticos e históricos de casos, excluyendo los años de pandemia (2020–2021). Desarrollado en colaboración con Mónica Lozada.

// Python
GitHub
~/proyectos/microeconometria-taller

Taller de Inferencia Causal

Material de enseñanza para un taller de microeconometría aplicada para estudiantes de pregrado de la Universidad Nacional de Ingeniería (UNI). Incluye ejemplos e implementaciones en Stata sobre MCO, variables instrumentales, regresión discontinua, diferencias en diferencias y modelos de elección discreta. El curso está en español.
